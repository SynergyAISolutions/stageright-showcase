# StageRight Design Direction

## Brand Personality
Professional, trustworthy, modern. Used by real estate agents who need to look credible. Premium SaaS tool feel, not a toy or tech demo.

## Design Principles
- Clean, generous whitespace
- Photography-focused — room images are hero content
- No dark mode needed (agents work in bright offices)
- Subtle animations only
- Mobile-first — agents often on phones at properties

## Colour Palette
- Primary: Deep navy or teal (trust, professionalism)
- Accent: Warm gold or coral (energy, real estate warmth)
- Backgrounds: White and light grey
- Text: Near-black (#1a1a1a)

## Typography
- Distinctive professional sans-serif for headings
- Clean readable body font
- Large text sizes — agents scan, not read essays

## Key UI Components
- Before/after slider: Full-width, smooth drag, mobile-friendly
- Image upload: Large drop zone, drag-and-drop + click
- Style selector: Visual grid with thumbnails, NOT a dropdown
- Regeneration: Clear "Try Another Look" button, not buried
- Loading state: Subtle animation during staging (~10-30s)

## Avoid
- Generic dashboard templates
- Overly rounded corners
- Gradient overload
- Stock photo vibes
- Cookie-cutter AI app aesthetic
